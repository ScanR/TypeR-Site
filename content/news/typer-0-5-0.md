---
title: TypeR 0.5 beta
date: 2024-06-25
version: 0.5.0
summary: The first build of TypeR, with fixes to the original TyperTools, customizable shortcuts and automatic page switching.
---

- **Bug fixes.** Multiple bugs from the original TyperTools have been fixed.
- **Text smoothing.** Fixed the bug that changed text smoothing from Strong to Smooth when increasing text size.
- **Stable auto-centering.** The text shape no longer changes when using auto-centering.
- **Customizable shortcuts.** You can now change the shortcuts for centering and pasting text.
- **Automatic page detection** when importing.
- **Automatic page switching** for a seamless workflow.
- **Resize TypeR.** The size limit of the TypeR window was lowered, so it can be much smaller.
