## New features and improvements

- **Maintain text layer proportions.** When resizing text with TypeR, the text box now adjusts automatically to maintain proportions.
- **Removed the 2s cooldown between actions.** Actions like inserting text can now be done without any enforced delay.
- **Fixed numeric image sorting.** Files such as `1.png` and `2.png` are now sorted numerically.
- **Clear keyboard shortcuts.** A new button removes assigned shortcuts.
- **New shortcut for inserting text.** You can now insert text on an existing text layer with a custom shortcut.
- **Fixed font style selection.** Selecting font weights (like bold or italic) now works correctly.
- **Themes.** TypeR now supports UI themes (CSS by `katsuo._`).
- **Text direction setting.** Choose left-to-right or right-to-left for languages like Arabic or Hebrew.
- **Optional autoscroll to style.** The autoscroll when clicking on a style can now be disabled in the settings.
- **Middle Eastern text options.** With Middle Eastern mode on, you can adjust diacritic offsets in the style editor.
- **Multi-word prefixes.** Prefixes with several words, such as `Big Title:`, are now supported.
