---
title: TypeR 0.9 beta
date: 2025-04-18
version: 0.9.0
summary: Duplicate a style folder, and keyboard shortcuts that survive a Photoshop restart.
---

- A line break is now added when inserting text on the current layer.
- Ability to duplicate a style folder.
- Keyboard shortcuts no longer reset when restarting Photoshop.
- If no text size is defined in your style, it uses the size of the selected layer.
