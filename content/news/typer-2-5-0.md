## New features

- New option to clear all selections at once (hold the "-" button)
- Added **bold/italic** Markdown and HTML support in the text area
- More customization options in settings
- New small-size editor to quickly change your style's text size
- Option to change the text size increment when editing a style
- Added a few tips (more coming later)

## Fixes

- Fixed a bug that prevented some keyboard shortcuts from working
