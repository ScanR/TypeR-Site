## 2.4.0

TypeR 2.4.0 improves the Multi-bubble workflow, introduces a Reset button and a new Windows installer.

### New features

- **Multi-bubble improvements.** Several quality-of-life improvements for the Multi-bubble mode, including a new visual indicator that shows when the mode is active. The default shortcut `Ctrl+Shift+M` (customizable in Settings) toggles it quickly.
- **Reset button.** A new button in the settings restores TypeR to its original factory configuration.
- **New Windows installer.** The Windows installer has been rebuilt for better stability.

### Fixes

- Refined the centering logic.
- Added a tooltip display when holding Shift in Multi-bubble mode.

## 2.4.1

- Fixed a bug that caused the autoleading percentage not to work properly.
- Fixed the installer, which wasn't working for some users.

## 2.4.2

- It's now easier to update TypeR, with a semi-automatic installation process.
- Fixed another centering bug.
